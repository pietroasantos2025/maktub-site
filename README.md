# Maktub — site recriado

Abra `index.html` em um navegador para visualizar o site. A pasta `assets` contém as imagens locais usadas na página, incluindo fotos do cardápio Anota AI e as imagens anexadas como referência.

Os botões de pedido levam ao cardápio do Maktub na Anota AI. Reservas e dúvidas levam ao WhatsApp informado na referência. O site é uma página estática, sem painel administrativo ou sistema de captura de contatos.
